# UsefulFood Reborn
Ajoute plus de nouvelles nourritures dans Minecraft. Il s'agit d'une réécriture plus récente de UsefulFood.

![2023-08-08 171407.png](../../../img/usefulfood/mL7a3PTWtuRVxwd.png)
#### Ajoute plus de nouvelles nourritures dans Minecraft. Il s'agit d'une réécriture plus récente de UsefulFood.

#### J'ai entièrement refait le code, mais les textures utilisent toujours celles de Usefulfood 1.8. Le code est donc sous licence MIT. Les textures sont sous licence Public Domain (UsefulFood les utilise).

#### Traduction
Vous pouvez soumettre des traductions pour UsefulFood Reborn via notre page [Crowdin](https://crowdin.com/project/usefulfood-reborn). N'hésitez pas à nous aider si vous parlez une langue ! Vous pouvez également soumettre des traductions via des pull requests.

#### Le but de ce mod est d'ajouter autant de nourriture utile que possible à Minecraft, sans détruire la sensation vanilla du jeu. Pas de recettes extrêmes et compliquées ! Le mod se veut simple et utile pour l'utilisateur, pour fabriquer de la nourriture à partir de choses dont on ne peut normalement pas faire de la nourriture, et pour ajouter une grande variété de nourriture afin de rendre Minecraft plus intéressant.

#### Fonctionnalités
Plus de 70 objets de nourriture
Nouveaux butins de mob pour les calmars.
GÂTEAUX !
Jus et smoothies
Tartes, sandwichs, soupes
Glaces
