# 处理机器

处理机器转换材料。大多数是有电机器，带有 1 个输入槽、1 个输出槽、一个电池槽和 4 个升级槽。除非另有说明，默认 EU 消耗为 **32 E/t**，默认处理时间为 **72 tick**（3.6 秒）。

## 甘蔗转换机（炼金方块）

![growableores_block](../../../img/industrial_elixir/machines/growableores_block_front.png)

一个简单的 1 输入 → 1 输出转换器，用于将**矿石甘蔗**转化为锭。1 级机器。

**使用：** 将矿石甘蔗放入输入槽，为机器供电，然后收集锭。

### 配方

| 输入 | 输出 |
|------|------|
| 青铜甘蔗 | 青铜锭 |
| 铅甘蔗 | 铅锭 |
| 神圣石甘蔗 | 神圣石锭 |
| 银甘蔗 | 银锭 |
| 钢甘蔗 | 钢锭 |
| 锡甘蔗 | 锡锭 |

## 铁炉

![iron_furnace](../../../img/industrial_elixir/machines/iron_furnace_front.png)

一个升级版的原版熔炉。燃烧固体燃料，使用原版熔炉 GUI，并使用标准熔炼配方进行熔炼。

## 电炉

![electric_furnace](../../../img/industrial_elixir/machines/electric_furnace_front.png)

一台电熔炼炉。1 级机器。使用原版熔炼配方进行熔炼，但由能量而非燃料驱动。

## 感应炉

![induction_furnace](../../../img/industrial_elixir/machines/induction_furnace_front.png)

一台具有热量机制的双输入熔炼炉。2 级机器。同时处理两个输入槽（每个槽最多 16 E/t）。

**使用：** 熔炉在运行时积累热量（0–100）。温度越高，每件物品所需的能量越少——从每件 **6000 E** 降到每件 **195 E**。红石信号可防止热量衰减（可用红石反相升级反转）。
