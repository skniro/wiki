# 工业灵药（Skniro's Industrial Elixir）

欢迎来到「工业灵药」——一个工业与自然交织共存的世界。
「工业灵药」是一款注重循序渐进与探索体验的 Minecraft 科技自动化模组。它不会一开始就用复杂的系统和大量数据压迫玩家，而是希望陪伴你慢慢成长：从简单的工具开始，制作第一台机器，逐步建立属于自己的工厂与自动化网络。
粉碎矿石、提炼材料、加工零件，看着第一条生产线在你的手中运转，每一次升级都会带来新的成就感。

## 这是什么？

「工业灵药」是一款专注于机械、自动化、能源与资源加工的 Minecraft 科技模组，同时保持轻松易上手的成长路线。

- **循序渐进的工业旅程** — 从粉碎机、压缩机等基础设备开始，逐步发展到电炉、感应炉、金属成型机以及更高级的工业科技。
- **打造属于你的能源网络** — 利用煤炭、流体、太阳能、风能等方式发电，连接设备，管理能源，建立独一无二的工业体系。
- **能够生长的资源** — 矿物不再只能通过挖掘获得。种植特殊矿物作物，培育橡胶树，建立可持续的资源生产方式。
- **工业也可以很温暖** — 种植咖啡豆，制作饮品，在温泉旁稍作休息。你的工厂也可以成为一个舒适的家。
- **更高层次的科技等待探索** — 当你准备好后，可以接触反应堆、复制技术以及量子级设备等先进系统。

## 你可能会喜欢它

- 完整的材料加工流程：粉碎、提纯、精炼，并将资源转化为高级组件。
- 多样化的能源生产与储存方式，满足不同规模工厂的需求。
- 通过管道与自动化系统运输物品和流体。
- 可种植矿物、橡胶树以及农业系统，让资源获取更加丰富。
- 兼容 JEI / REI，方便查询配方。

无论你是刚接触科技模组的新玩家，还是经验丰富的科技模组玩家，都欢迎来到「工业灵药」的世界，创造、探索，并建立属于自己的工业奇迹。
