# 工业灵药

**工业灵药** 是一个适用于 **Fabric** 和 **NeoForge** 的 Minecraft 科技模组，添加了大量工业机械、EU 风格的能量系统、流体、管道、矿物处理，甚至可种植的矿石。

## 功能

- **能量系统** – 多等级 EU 风格电力，配有电缆（锡、铜、金、高压、玻璃纤维）、电池、变压器和能量存储箱（储能箱、CESU、MFE、MFSU）。
- **发电** – 火力发电机、流体发电机、风力发电机、太阳能发电机（最高量子级）、核反应堆、神圣反应堆等。
- **矿物处理** – 粉碎机、压缩机、金属成型机、提取机、洗矿机、热能离心机、感应炉、热高炉，以及完整的粉碎/纯净矿粉处理链。
- **流体与管道** – 木制/石制流体管道、物品管道、流体储罐、流体发电机和自动流体运输。
- **高级机器** – 分子转换机、复制机、物质生成机、回收机、方块切割机、区块加载器、作物种植机、咖啡机、自动售货机，以及酿造/炼金系统。
- **核能与神圣反应堆** – 反应堆组件，包括燃料棒、冷却单元、散热片、中子反射板和反应堆隔板。
- **可种植矿石** – 以作物的方式种植矿物材料，而非开采。

## 能量基础

能量以 **EP**（模组的 EU 风格单位）计量。不同的机器、电缆、电池和发电机运行在不同的**能量等级**：

| 等级 | 最大输入/输出 |
|------|--------------|
| 1 级 | 32 E/t |
| 2 级 | 128 E/t |
| 3 级 | 512 E/t |
| 4 级 | 2048 E/t |
| 5 级 | 8192 E/t |
| 无限 | `Integer.MAX_VALUE` |

每台机器都可以用最多四个**升级模块**来改变其速度、能量等级、存储量或红石行为。

## 入门指南

1. **熔炼矿石**获得铜、锡、铅、青铜、银和钢锭。
2. **建造粉碎机**将矿石变成粉碎矿，然后使用**洗矿机**和**热能离心机**获得纯净矿粉。
3. **建造金属成型机**将锭轧成板，再将板切割成电缆。
4. **制作电池和电缆**来存储和运输你的第一台**火力发电机**产生的能量。
5. **升级你的电力**，使用太阳能发电机、风力发电机、储能箱，最后是核能/神圣反应堆。
