# Torcherino（非官方）

![屏幕截图 2025-07-16 211157.jpg](../../../img/torcherino/vRbpasfXAxtNPc9.jpg)

*Torcherino* 是一个简单而强大的 Minecraft 模组，引入了一种特殊的火把，可以加速附近方块的随机刻速度。这意味着农作物长得更快，树苗成熟得更快，草传播得更迅速——而且不需要改变您的世界的全局刻设置！

*这是一个非官方的 Torcherino 发布版本。在官方将 Torcherino 更新到更高版本之前，我会将它移植到更高的 Minecraft 版本。*

### 功能：

- 添加了一个独特的火把，在可配置的半径内提高随机刻速率
- 加速作物生长、树木生长、草的传播、树叶衰变等
- 可通过模组配置文件配置范围和刻速度倍率
- 与原版和许多模组方块与作物兼容
- 性能友好且易于使用！
-

让植物生长更快，熔炼矿石更快，提高刷怪笼速度。有一个主要的 Torcherino，然后还有各种升级品可以叠加在上面。这些功能中的许多都可以在模组配置文件（名为 Torcherino.cfg，位于 config/sci4me 文件夹中）中进行配置。

放置 Torcherino 后，它默认处于停用状态。您必须右键点击它并使用 GUI 将其设置调整为您偏好的范围和速度。
